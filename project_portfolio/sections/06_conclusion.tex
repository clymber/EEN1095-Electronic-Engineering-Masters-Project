\section{Conclusion}
\label{sec:conclusion}

The approved research question was only partly answered. A documented staged
investigation progressed from point-wise insertion-loss baselines to a
whole-curve model and then to a design-conditioned approximation of the
complete complex 12-port response over 200 frequencies for one PCB topology.
The full-matrix model reduced test complex MAE from 0.0804 for the training-mean
matrix to 0.0686 and guaranteed reciprocity by construction. This establishes
feasibility beyond a design-independent reference, but not task-specific
accuracy sufficient for signal-integrity decisions: no engineering tolerance
or downstream decision criterion was evaluated.

The physical-validity findings were more nuanced. The non-physical negative
insertion-loss behaviour reported by Chen and Tan \cite{chen2021physics} was not
observed in the selected full-matrix predictions on the sampled test grid: none
of the 281,200 design--frequency matrices violated passivity. The evaluated
cases therefore did not reveal a passivity failure requiring correction. The
causality residual was a relative finite-band diagnostic rather than a
pass/fail test; it neither identified a specific causality violation nor
certified causal behaviour. Neither property was enforced, so the planned
enforcement and constrained-versus-unconstrained comparison were not completed.
The controlled study varying each physical parameter was also not completed.
No electromagnetic simulation was timed, so reduced simulation cost was not
demonstrated. The findings are limited to the selected topology and sampled
ranges, one selected training seed, and a test set that was held out from
fitting but inspected during development.

The principal contribution is therefore a documented exploration in which
selected-path accuracy, coverage of the complete matrix and physical validity
are evaluated separately. Generic point-wise complexity did not consistently lower
$IL_{7,1}$ error, the whole-curve formulation produced the strongest retained
selected-path result, and reciprocal reconstruction enabled complete-matrix
prediction. Reciprocity was guaranteed, passivity was observed on the sampled
grid, and causality remained a limited diagnostic.

Future work follows directly from these limits. Loss weighting should target
weak responses and deep transmission nulls. To test physical validity beyond
the sampled observations, passivity and stronger broadband causality constraints
should be implemented and compared with an otherwise matched unconstrained
model. Each physical parameter should then be varied with the others controlled,
examining S-parameters, insertion loss, return loss and crosstalk. Multiple
training seeds and an untouched confirmatory test should quantify
model-selection uncertainty. Related topologies and explicit
interpolation/extrapolation protocols should then test generalisation. A
longer-term extension would be a topology-aware universal model spanning all
PCB topologies in the full SI/PI-Database, which would require a common
representation for different parameter sets and port counts. Finally, inference
should be timed against a defined electromagnetic-simulation baseline before
claiming computational savings.
